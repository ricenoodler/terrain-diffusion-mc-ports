Unofficial Terrain Diffusion MC port for Minecraft/Fabric 26.1.2.



Original project: xandergos/terrain-diffusion-mc

This fork is not an official upstream release.



Download guide:

\- windows-directml: recommended for most Windows GPU users.

\- cuda: for NVIDIA users with CUDA/cuDNN installed.

\- cpu: fallback/testing build; slower, but does not require GPU backend setup.



Tested:

\- Minecraft 26.1.2

\- Fabric Loader 0.19.2

\- Fabric API 0.152.1+26.1.2

\- Java 25

\- Terrain Diffusion world type

\- Vanilla Customize button world-scale settings



Notes:

\- Heavily modded clients may need around 10–12 GB RAM.

\- Voxy/Voxy World Gen may increase RAM usage or stutter with Terrain Diffusion worlds.
